# Python OOP Practice

A collection of Object-Oriented Programming exercises built 
while learning Python before Semester 3.

## Projects

### BankAccount
A bank account system with deposit, withdraw, and balance features.

### SavingsAccount
Extends BankAccount with an interest rate and add_interest() method.

### Library
A library management system to add, borrow, and return books.

## How to Run

```bash
python bank.py
python savings.py
python library.py
```

## What I Learned
- Classes and objects
- Inheritance and super()
- __str__ and __repr__
- Edge case handling
